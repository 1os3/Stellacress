# Stellacress 存档格式 1

档案数量不设上限，每个档案位于 `user://saves/archive_<id>`。系统动态扫描档案目录并分配递增 ID；旧版 `slot_1..3` 仍可读取。开发和自动化测试通过构造参数把存储根重定向到项目内。

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 格式/定义/PRNG 版本、槽名、run seed、下一个 ID、任务状态与命名品系。 |
| `plants.bin` | 固定字段 PlantRecord 与 UTF-8 显示名。 |
| `genomes.bin` | 两组同源染色体、0.01 cM 量化 Segment 和 Variant。 |
| `events.bin` | 显式字典组成的事件日志 JSON。 |
| `trials.bin` | 试验、重复观测和环境引用 JSON。 |
| `mutations.bin` | 突变注册表 JSON。 |
| `research.bin` | QTL 区间、识别等级与置信度 JSON。 |

写入先落到同目录 `.tmp`，旧文件改名为 `.bak` 后再提交新文件；`manifest.json` 最后写入。载入时拒绝未知 `save_format_version`、`species_definition_version` 或 `prng_algorithm_version`，并逐个校验 Genome 不变量。

删除档案需要界面二次确认。删除服务会解析并验证目标路径必须是存档根目录的直接后代，然后递归删除该档案目录；不会接受存档根本身或根目录之外的路径。
