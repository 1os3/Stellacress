# 测试与性能基准

在项目根目录使用随项目附带的 Godot 4.7.1 控制台版本：

```powershell
.\GodotEditor\Godot_v4.7.1-stable_mono_win64_console.exe --headless --path . --script res://tests/test_runner.gd
```

回归套件固定种子并覆盖：48 位点定义、AA×aa、Aa 自交 1:2:1、6 cM Haldane 重组率、跨染色体独立分配、Segment/祖源不变量、确定性、环境表型、研究解锁、教程恢复、自定义杂合 Genome、不限数量档案、安全删档、存档往返和主场景实例化。

性能基准：

```powershell
.\GodotEditor\Godot_v4.7.1-stable_mono_win64_console.exe --headless --path . --script res://devtools/benchmark.gd
```

基准生成 5000 个真实 Genome，不实例化植物 Node，并校验全部 Genome。耗时数据只在同一机器与引擎版本间比较。
