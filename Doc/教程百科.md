# 教程百科内容范围

游戏将“新手引导”和“教程百科”明确分开：

- **新手引导**是工作台右上角的八步操作浮层，负责提示下一步在哪里点击。
- **教程百科**是可独立打开的知识中心，负责解释概念、规则、玩法、工具和任务思路；可从主菜单、工作台顶部及相关功能旁的上下文按钮进入。

## 当前教程目录

| 分类 | 主题 |
| --- | --- |
| 入门 | 游戏目标与完整育种循环 |
| 遗传概念 | 二倍体、等位基因、纯合/杂合、染色体图谱、cM、连锁、重组、主效基因、QTL、显性、上位性、突变 |
| 育种玩法 | 杂交、自交、回交、候选筛选、Pareto、目标权重、遗传多样性 |
| 试验研究 | 表型、环境、G×E、重复试验、标准误、QTL 解锁 |
| 谱系祖源 | 家谱、基因组祖源、Segment 与实际供体比例 |
| 任务攻略 | 标准任务 A/B/C 的目标与通用思路 |
| 工具指南 | 基因组工坊的基础祖源、A/B 编辑、纯合/杂合、Variant Override 和信息可见性 |
| 系统说明 | 不限数量档案、删档、确定性随机合同 |
| 速查 | Genome、Haplotype、Homolog、Genotype、Phenotype、QTL、G×E、cM 等术语 |

教程百科支持标题、关键词和正文搜索。染色体视图、试验页和基因组工坊均提供直接打开对应文章的按钮。
